# PFE – Internal Social Network (Angular & Spring Boot)

## Project Description
This project is an internal social network developed as part of my Final Year Project (PFE).  
It allows users to create posts, comment, like, share, and manage their profiles in a secure environment.

## Technologies Used
- **Front-end:** Angular, HTML5, CSS3, TypeScript
- **Back-end:** Spring Boot, Java
- **Database:** MySQL
- **Tools:** Git, GitHub, Visual Studio Code

## Key Features
- User and profile management
- Create, edit, and delete posts
- Likes, comments, and post sharing
- Notifications and internal messaging system
- Media management (images and videos)
- Modern and responsive user interface
